# Gem Defense (рабочее название)

Мобильный tower defense про выведение монстров. Каждый раунд подселяешь 5 случайных монстров
и оставляешь одного. Клетки остальных запечатывают железом, и они становятся стенами лабиринта. Перед этим
можно скрещивать: одинаковые монстры дают потомка старше, а разные виды по скрытым правилам дают гибриды.

Играть: https://nanaironika.github.io/Game_1/
Дизайн-документ: [docs/design.md](docs/design.md) · Роудмап: [docs/roadmap.md](docs/roadmap.md)

**Баланс** (монстры, гибриды, враги, волны) лежит в таблицах в папке [`data/`](data). Справка по столбцам: [docs/data.md](docs/data.md).

Стек: TypeScript + Phaser 3 + Vite. Позже его упакуем в приложения для Android и iOS через Capacitor.

## Как играть
1. Нажимай на пустые клетки, чтобы подселить 5 монстров. Путь врагов полностью перекрыть нельзя.
2. Выбери одного из новых монстров (они подсвечены жёлтым):
   - **Оставить**: клетки остальных новых монстров запечатают.
   - **Скрестить…**: отметь партнёров среди новых монстров и нажми «Скрестить».
3. Отбей волну. Враги идут S → 1 → 2 → 3 → E.

Найденные гибриды записываются в **Бестиарий**. Игра сохраняется между волнами.

## Запуск
```
npm install
npm run dev     # дев-сервер
npm run build   # сборка в dist/
```
