# Gem Defense (рабочее название)

Мобильный tower defense: каждый раунд ставишь 5 случайных самоцветов, оставляешь один,
остальные превращаются в камни и становятся стенами лабиринта. Самоцветы можно сливать
в более сильные и собирать из них особые башни по рецептам.

Стек: TypeScript + Phaser 3 + Vite. Позже его упакуем в приложения для Android и iOS через Capacitor.

## Как играть
1. Нажимай на пустые клетки, чтобы поставить 5 самоцветов. Путь врагов полностью перекрыть нельзя.
2. Выбери один из новых самоцветов (они подсвечены жёлтым):
   - **Оставить**: самоцвет остаётся, остальные новые станут камнями.
   - **Слить 2 / Слить 4**: если среди новых есть одинаковые, оставленный получит +1 или +2 уровня.
   - **Создать**: если среди новых есть набор для рецепта, получится особая башня.
3. Отбей волну. Враги идут S → 1 → 2 → 3 → E.

Золото тратится на «Шанс качества»: после покупки чаще выпадают самоцветы высокого уровня.

## Запуск
```
npm install
npm run dev     # дев-сервер
npm run build   # сборка в dist/
```
