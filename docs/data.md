# Таблицы баланса (папка `data/`)

Игра читает четыре таблицы при запуске. Если в таблице ошибка, вместо игры появится список проблем:
файл, строка, столбец и что не так.

| Файл | Что внутри | Одна строка — это |
|---|---|---|
| `monsters.csv` | базовые виды монстров | один вид на одном уровне (возрасте) |
| `hybrids.csv` | гибриды и их рецепты | один гибрид |
| `enemies.csv` | типы врагов | один тип врага |
| `waves.csv` | состав волн | одна группа врагов в волне |

## Как редактировать
- **Excel:** открыть файл двойным кликом. Сохранять как **«CSV UTF-8 (разделитель — запятая)»**, иначе русские
  буквы испортятся. Excel в русской локали сохраняет с разделителем `;`, игра это понимает.
- **Google Таблицы:** Файл → Импорт → Загрузить. Обратно: Файл → Скачать → CSV.
- **VS Code / любой текстовый редактор:** столбцы разделены `;`.
- Дробные числа можно писать и через точку, и через запятую: `0.8` = `0,8`.
- Пустая ячейка в необязательном столбце = «нет свойства» (0).
- Строки, начинающиеся с `#`, игнорируются: удобно для комментариев или временного отключения.
- **Уровни в таблицах считаются с 1:** 1 Детёныш, 2 Молодой, 3 Взрослый, 4 Матёрый, 5 Альфа.
- Столбцы `id`, `species` и `enemy` — это внутренние имена латиницей. По ним таблицы ссылаются друг на друга, поэтому
  при переименовании их нужно менять везде. Отображаемое имя — столбец `name`.

## Общие столбцы атаки (monsters и hybrids)
| Столбец | Смысл | Пример |
|---|---|---|
| `damage` | урон одного удара | `12` |
| `attack_speed` | ударов в секунду | `0.8` |
| `range` | дальность в клетках | `3` |
| `splash` | радиус урона по области в клетках (соседи получают 50%) | `1.2` |
| `slow` | замедление цели в %, на 2 секунды | `30` |
| `poison` | урон ядом в секунду, 3 секунды, броню игнорирует | `5` |
| `targets` | сколько целей бьёт одновременно (пусто = 1) | `2` |
| `crit` | шанс двойного урона в % | `25` |
| `aura` | ускорение атаки соседей в радиусе 2.5 клетки, в % | `10` |
| `color` | цвет-заглушка до появления арта | `#e0403a` |

## monsters.csv
| Столбец | Смысл |
|---|---|
| `species` | внутреннее имя вида (латиницей), например `flamer` |
| `level` | уровень 1–5. У каждого вида должны быть все 5 строк |
| `name` | имя вида. Название возраста добавляется само («Жаровик: Молодой») |
| `description` | описание |
| + общие столбцы атаки | |

Чтобы добавить новый вид, добавьте 5 строк с новым `species`. Он сразу начнёт выпадать в игре.

## hybrids.csv
| Столбец | Смысл |
|---|---|
| `id` | внутреннее имя гибрида |
| `name`, `description` | имя и описание |
| `parent_1` … `parent_4` | родители в формате `вид:уровень`, например `jelly:1`. Минимум 2 родителя, лишние столбцы оставить пустыми |
| + общие столбцы атаки | |

Порядок родителей не важен. Два гибрида с одинаковым набором родителей — ошибка.

## enemies.csv
| Столбец | Смысл |
|---|---|
| `id`, `name`, `description` | внутреннее имя, отображаемое имя, описание |
| `speed` | скорость в клетках в секунду |
| `lives_cost` | сколько жизней игрок теряет, если враг дошёл до выхода |
| `armor` | броня в %: на столько уменьшается урон от ударов (яд проходит полностью) |
| `immune_slow` | `да` или `нет`: иммунитет к замедлению |
| `immune_poison` | `да` или `нет`: иммунитет к яду |
| `size` | размер кружка-заглушки (радиус в пикселях) |
| `color` | цвет-заглушка |

Здоровья и награды здесь нет: они задаются в `waves.csv`, чтобы один и тот же враг мог крепнуть от волны к волне.

## waves.csv
| Столбец | Смысл |
|---|---|
| `wave` | номер волны. Волны должны идти без пропусков: 1, 2, 3… Количество волн = самый большой номер |
| `enemy` | `id` врага из `enemies.csv` |
| `count` | сколько врагов в группе |
| `hp` | здоровье каждого врага группы |
| `gold` | золото за убийство одного врага |
| `delay` | через сколько секунд от начала волны выходит первый враг группы |
| `interval` | секунд между врагами группы |

В одной волне может быть несколько групп: просто несколько строк с одним номером. Например, волна 8:
ходоки сразу, а через 10 секунд — панцирники.

## Что пока задаётся в коде (`src/data.ts`)
Названия возрастов, шансы породы и их цены, количество монстров за раунд, стартовые жизни, бонус за волну
(`5 + номер волны`). Если захочется — перенесём и это в таблицу.
